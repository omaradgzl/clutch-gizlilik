# Clutch — Gizlilik Politikası

Bu depo yalnızca [Clutch](https://play.google.com/store/apps/details?id=com.clutch.app)
uygulamasının gizlilik politikasını barındırır.

**Yayınlanan sayfa:** https://omaradgzl.github.io/clutch-gizlilik/

Sayfa elle yazılmaz; Clutch deposundaki `GIZLILIK.md` dosyasından
`scripts/gizlilik/build.mjs` ile üretilir. Politikayı değiştirmek için
kaynağı değiştir, betiği çalıştır, buradaki `index.html`'i güncelle.

Uygulamanın kaynak kodu bu depoda değildir.
